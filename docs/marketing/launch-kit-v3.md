- 标签 **3-5 个为最佳**，多了被识别为 spam
- 视频里只口播 + 字幕 "GitHub 搜 MouseClaw"，**不写完整 URL**
- 发布后 30 分钟内**主动回 5 个评论**激活算法
- 评论引导话术：「这是开源项目，GitHub 搜 MouseClaw 就行」「Mac 上能用，Windows 还没适配」

1/ It's called MouseClaw — `mouse` because it's a cursor AND a tiny pet.
   The pun is the whole product 🐭

2/ Architecture:
   - Tauri 2 (Rust + WebView)
   - sherpa-onnx for local speech (zh-en bilingual or en-only)
   - Pluggable AI backend: Claude / Codex / OpenClaw / Hermes
   - 12MB installer

3/ Three things it can do that I haven't seen elsewhere:
   - Voice → text directly at cursor (any input box, any app)
   - Drop a file on the pet → it eats it → AI now has context

   - Your prompts don't leave your machine
