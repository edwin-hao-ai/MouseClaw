定时任务 / 心跳 · scheduled tasks

v0.5 提案 · 2026-05-21 · 「每天早上整理 AI 新闻」「每隔 2 小时看看要紧邮件」—— 一句话设好，到点自己跑

核心张力：MouseClaw 的人设是「平时不存在、安静」。而定时任务天生是主动打扰—— 两者怎么调和？答案是三条纪律：① 入口零学习，对桌宠说一句人话就建好，不弹表单； ② 投递克制，到点做完只冒一个不抢焦点、几秒自动消失的轻气泡，结果永久存进任务窗你想看再看； ③ 安全收口，定时任务永远走 A 模式、永远不截屏、永远不往你当时的 app 里打字。 下面把整条用户旅程做成可点的 demo（已拍板：一句话创建 · 轻气泡投递 · 固定/间隔/工作日全模型）。

⑤ 定时模型：人话 → 结构化（已拍板「固定 + 间隔 + 工作日」全集）

用户说解析成schedule JSON
每天早上 8 点…每天 08:00{"kind":"daily","time":"08:00"}
工作日下午 6 点…工作日 18:00{"kind":"weekday","time":"18:00"}
每周一早上 9 点…每周一 09:00{"kind":"weekly","days":[1],"time":"09:00"}
每隔 2 小时…（心跳）每隔 2 小时{"kind":"interval","everyMinutes":120,"active":"09:00-22:00"}
每月 1 号…每月 1 号 10:00{"kind":"monthly","day":1,"time":"10:00"}

心跳类（interval）多一个 active 活跃时段：openclaw heartbeat 直觉是「定期醒来看看要不要做事」， 但半夜每 2 小时弹一次会烦 → 默认只在白天活跃时段跑，半夜静默。这个时段也能用人话改（「只在上班时间」）。

⑥ 用户怎么知道有这功能？（可发现性 — UX 第 1 问）

入口说明
① 直接说（主路径）召唤桌宠后说「每天…帮我…」，backend 识别到调度意图 → 回 [SCHEDULE] 标记 → 弹确认卡。和现有 Mode B [INSERT_AT_CURSOR] 同一套标记机制，4 个 backend 共用 system prompt 自动生效。
② 托盘菜单新增 ⏰ 定时任务… 一项（双语），打开管理窗。常驻可见 = 长期可发现性。
③ 桌宠右键菜单PetMenu 加 ⏰ 定时任务 项，就近入口。
④ 一次性发现提示用过桌宠 N 次后，某次空闲冒一条轻提示：「💡 想让我每天定时帮你做点事吗？说一句『每天早上整理 AI 新闻』试试」。只出现一次（seen_schedule_hint 标记），不打扰。

⑦ 全流程 UX 10 问 · 安全红线 · 失败模式（动手写 Rust 前答完）

  • 红线 1 · 永远 A 模式：定时任务绝不在到点时往你当时碰巧在用的 app 模拟键盘写字（B 模式）。8 点你在写邮件，它绝不偷偷插字。与「不写终端」同级红线 → 即使任务结果含 [INSERT_AT_CURSOR] 也强制忽略。
  • 红线 2 · 永远不截屏：你不在主动问，偷抓屏幕既无意义又侵犯隐私。任务走 backend::ask_text_only（纯文本，无图），prompt 自包含。
  • 首次使用：确认卡把「我理解成了什么」摊开给你看（时间 + 动作 + 投递方式都可见）→ 不对就「改一下」用人话纠正。第一次就不会建错。
  • 不抢焦点 / 不打扰（UX 第 6+9 问）：overlay 窗 focus:false，投递气泡不夺键盘焦点；几秒自动消失；你正在打字时不弹（延到下一个自然停顿）。
  • 失败模式 · Mac 睡着了：定时器睡眠中不触发。醒来后若错过的是当天且仍在宽限窗内 → 补跑一次；否则标「错过」并显示下次时间。绝不堆积——关机一周回来不会一次跑 7 遍。
  • 失败模式 · 断网 / backend 挂：因为是你「预约」的不是此刻要的，不弹刺眼错误气泡打断你 → 安静记进任务窗 + 自动重试一次 + 可手动重试。
  • 取消 / 后悔：确认卡 Esc 取消；管理窗一键开关（暂停不删）/ 删除；正在跑的走 ai_queue 排队，让它跑完即可（结果存窗口，气泡自消）。
  • 状态可见性：跑的时候三点忙碌 badge（任何视图可见）；管理窗每条显示下次/上次✓✗。你永远不会「不知道它在不在做、做完没」。
  • 不抢 CPU：套 ai_queue::acquire() 串行 + niced 子进程 → 跟你手动触发的任务、本地听写排队不打架（继承现有硬规则）。
  • 长期不烦（UX 第 10 问）：轻气泡几秒消失 + 可整条静音（管理窗关开关但保留）+ interval 默认只白天跑。惊艳一次 vs 每天烦的平衡点。

// ~/.mouseclaw/schedule_runs.jsonl —— 每次跑的完整结果（仿 sessions.jsonl，append-only）
