① 视频拆分方案 · 5 个单一 demo + 1 个 overall

用户在不同平台关注不同卖点。先做 5 个 12-15 秒的单一 demo（每个聚焦一个功能），再剪一个 60-75 秒 overall。这样：

  • 单一 demo 适合 A/B 测试 — 一个号发 5 条不同内容，看哪个最爆，下次重点推这个角度
  • overall 长片适合视频号 / B 站（视频号 30-60s 完播友好，B 站允许更长）
  • 素材一份多用 — 单一 demo 的镜头可以直接进 overall timeline

② AI 配音工具选择

🅰 火山引擎 TTS

音色：「晓萌」（活泼女声）/「硕」（沉稳男声）

✅ 国内最自然中文 TTS

✅ API 简单，curl 调用

✅ 免费额度足够（每月 10 万字）

⚠️ 需要注册账号 + 拿 API key

链接：volcengine.com/product/tts

🅱 剪映 / CapCut export 音频

音色：剪映"晓萌""硕"同款（实际就是火山）

✅ 零代码 · 剪映里直接配

✅ 可手动调语速 / 停顿

⚠️ 手动操作每条字幕都要点

⚠️ export 出 mp3 还要单独喂进 hyperframes 时间线

链接：lv.ulikecam.com

🅲 macOS 内置 say

音色：Tingting（中文女声）/ Daniel（英文男声）

✅ 零依赖，命令行直接生成

✅ 完全免费 + 离线

✅ 跟 hyperframes 集成最容易（脚本化）

⚠️ 音色比火山差一档（适合 v1，后续替换）

命令：say -v Tingting "..." -o out.aiff

我推荐分两阶段：
  1. v1（这周做）：macOS say + Tingting — 我能在 hyperframes 项目里直接写 shell 脚本一次生成所有配音文件。零成本、零阻塞，先把视频做出来发。
  2. v2（如果数据好）：火山引擎晓萌 — 注册账号 + 拿 key 后我帮你写 Python 替换脚本。音色差别在最终视频里能听出来，但 v1 跑数据时不需要那个差别。
极端方案：剪映手动配音也 OK，但要你手动操作 + 我无法自动化。

③ hyperframes 集成音频

hyperframes 当前不原生支持 audio track。两种集成方式：

方式 1 · hyperframes 出哑剧视频 → ffmpeg 后处理拼音频（推荐）

  1. hyperframes 渲染纯画面 mp4（无声）
  2. shell 脚本调 say 生成每句配音 aiff
  3. ffmpeg 把所有 aiff 拼接成单条 mp3，按 scene 时间码对齐
  4. ffmpeg 合成：ffmpeg -i video.mp4 -i audio.mp3 -c:v copy -c:a aac final.mp4

✅ 完全脚本化 · 每次改文案重跑就能出新版本

⚠️ 音视频对齐要算 timing；字幕从 hyperframes 出

方式 2 · 用剪映剪

  1. hyperframes 出无声视频 (mp4)
  2. 导入剪映
  3. 剪映里点点字幕 + AI 配音 → 直接 export

✅ 改字幕零成本

⚠️ 你要在剪映里操作每个 demo · 5+1 个视频要操作 6 次

我推方式 1 · macOS say + ffmpeg：6 个视频一个 shell 脚本跑完，下次改文案 = 改一行配置 + 重跑。
