认识一下你的桌宠

给桌宠起名 + 选性格。性格只改语气、不改答案对错(硬约束)。下方 9 款皮肤同屏 —— 换皮肤、改名、切性格都即时反映在头顶气泡。每个性格卡里是它对同一句 「帮我看下这段代码 🐛」的不同回法,让你凭体感选,不用读说明书。

main.rs — mouseclaw
fn build_prompt(bundle: &ContextBundle) -> String {
  // 视觉 + 音频 + 记忆 三路合流
  let mem = bundle.memory.unwrap_or("");
  format!("{}\n[记忆]\n{}", bundle.transcript, mem)
}
