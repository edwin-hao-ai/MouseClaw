① 病毒性 5 要素（我会怎么做）

要素原理demo 里怎么落地
1. 钩子 3 秒 第一秒留人，第三秒勾人。失败 = 80% 用户划走 0-1s：满屏红色 "You've reached your limit"（OpenAI 限流）
1-3s：背景一颗大像素老鼠从底部跳进来，盖住红字
2. 反差冲突 预期 vs 实际的落差 = 病毒分享理由 "AI = 云上的巨头" 预期 vs "我电脑里养一只老鼠" 实际
视觉反差：高大上 ChatGPT logo → 小小一只像素老鼠
3. 情绪节奏 紧张 → 好奇 → 惊喜 → 满足 → 行动 5 步骤 限流(紧张) → 老鼠登场(好奇) → AI 干活完成(惊喜) → "12MB · 本地"(满足) → "GitHub 搜"(行动)
4. 记忆锚点 名字 + 视觉双绑定，用户隔几天还能搜回来 "老鼠 + 桌面 AI" → MouseClaw 名字 3 次出现：开头 lower-third、过程中老鼠张嘴气泡、结尾大字幕
5. 行动 CTA 说"链接在简介"是 1% 转化；说"GitHub 搜 XXX"+ 给具体动作能到 5-10% 结尾 2 秒大字 GitHub 搜 MouseClaw（搜索框光标闪烁动画，模拟用户已经在搜）

② 让用户"心心念念"的 3 个心理钩

核心心理学：你不是要他立刻下载，是要他晚上躺床上还想着这视频。3 个钩子：

钩 1 · 留白 + 反常识

视频里不解释"为什么是老鼠"。让用户想——为什么是老鼠？为什么叫 MouseClaw？这种"未解之谜"会留在脑子里，触发自发搜索。

实施：视频里老鼠只是出现 + 干活，不解释来源。结尾字幕只说"GitHub 搜 MouseClaw"，不解释名字含义。让用户带着问号去搜。

钩 2 · 稀缺感 + 内行人

暗示"只有少数人知道"。技术圈用户对"还没火的好东西"特别敏感。

实施：lower-third 加一句小字 "100 人在用 · 开源"（具体数字可以是真实 Star 数）。视频中后段插一句旁白 "还没什么人知道"。

钩 3 · 隐喻反复

"喂老鼠""老鼠帮你写""老鼠睡了""老鼠跟着光标"—— 把日常动作全用"养宠物"语言重新组织。每听一句都加强一次"它是宠物 + 它是 AI"双重身份。

实施：所有旁白动词换成动物拟人。"AI 回复"→"老鼠告诉你"。"打开文件"→"喂它"。"按快捷键"→"喊它"。让用户脑子里产生新词条。

③ 全动画方案 · 怎么不录屏也"真实"

元素真实感怎么来
ChatGPT 报错网页HTML/CSS 1:1 复刻 chatgpt.com 报错 toast。字体用 system-ui，红色精确 #ff4747，按钮 hover 状态都做
桌面背景macOS Sequoia 默认壁纸（pixabay 找类似的渐变）+ 顶部 menubar mock（时间走动）
浏览器窗口HTML/CSS mock Safari/Chrome 的 chrome（红黄绿圆点 + 地址栏 + 标签栏）
微信输入框mock 微信聊天窗口（公开 UI 元素：绿色发送按钮、灰色输入框、对话气泡）
鼠标光标SVG macOS 鼠标光标（黑 + 白边）+ GSAP 移动动画（cubic-bezier 不要 linear）
键盘按下视觉屏幕角落浮一个 mockup ⌘ ⇧ Space chip，按下变深色 0.2 秒
像素老鼠动画已有的 SVG sprite（睡/听/想/跳/吃）+ 加 sub-pixel 抖耳朵 + 眨眼 keyframes
AI 流式吐字用 GSAP onUpdate 按 progress 切 string（你以前实现过的方式，参考 demo-zh 已有的 splitString 动画）
文件拖动SVG PDF 图标 + GSAP 位移动画 + 老鼠张嘴时的 svg morph（已有 feed-wait sprite）
关键差异：现有 marketing/demo-zh/index.html 已经是 hyperframes 静态文字 + 桌宠。我会把它扩展成有"假应用窗口"+"假鼠标光标"+"假浏览器"的 mock 系统。每个 mock 元素都是 HTML+CSS，可被 GSAP 操控。

⑤ Demo 1 的逐秒分镜（下次开工蓝图）

这是我会写进 marketing/demo-zh/index.html 的精确分镜（每 0.5 秒一个事件）：

时间画面动效 (GSAP)配音 (剪映 AI)
0.0-0.8s 满屏 ChatGPT 红色报错 toast "You've reached your message limit" toast scale 0→1.2→1 弹出，背景模糊 —（让画面自己讲）
0.8-2.0s 手指狂点页面（光标快速点击效果），toast 不消失 光标 jitter 4 次，每次点击波纹 "今天我把 ChatGPT 开除了。"
2.0-3.0s 浏览器关闭动画，露出 macOS 桌面 窗口 scale 0.95 + opacity 0，桌面渐显 "请了一只老鼠。"
3.0-4.5s 右下角像素老鼠 zoom in，从睡眠 → 听 sprite 切换 scale 0.3→1.0 cubic-bezier(0.34, 1.56, 0.64, 1)（弹性） "按住 ⌘⇧空格 + 说话 ——"
4.5-7.0s 左侧浮出 mock 浏览器（一篇博客草稿），右下角老鼠头顶气泡显示用户说的话："帮我把开场白改得更打动人"（流式打字） 气泡 from-bottom + 文字逐字 stagger 0.05s "它能听见你 +"
7.0-11.0s 老鼠气泡变样式（success），开始流式吐 AI 回复："其实第一句话不该说『我们今天来聊聊』，可以试试：『假如你只有 5 分钟，你会怎么解释 X 给孩子听？』" 字逐字浮现，光标在 AI 回复结尾闪烁 "还能动手帮你改文件。"
11.0-15.0s 切镜：手柔慢拖一个 PDF 图标到老鼠嘴边，老鼠张嘴吞下，气泡 "🍽 已吃下 论文.pdf" PDF 图标 motion path 弧线，老鼠张嘴 morph "喂它一份文件 —— 它就能读懂。"
15.0-19.0s 切镜：微信聊天窗口，输入框光标闪烁。屏幕浮 fn 按下视觉，老鼠 listen 状态，字逐个落到输入框 "今晚六点半，西湖见怎么样？" 字符逐个 from y=-10 落入 + 标点自动加上 "长按 fn —— 字直接打到光标里。"
19.0-23.0s 桌面右下角，老鼠回到睡眠 sprite。屏幕中央浮三个 chip："12 MB · 100% 本地 · 0 字节上云" chip 从底部 stagger 0.2s 弹出 "12 兆，本地推理，你的话不上云。"
23.0-27.0s 屏幕中央一个 Spotlight 搜索框样式的元素，光标在框里"打字"出 "MouseClaw" 字符逐个出现 + 搜索框周围波纹 + 底部 chip "100 人在用 · 开源" "还没什么人知道。GitHub 搜 MouseClaw。"
27.0-30.0s 大字幕 "MouseClaw" + 小字 "桌面养只老鼠，AI 帮你干活" + 老鼠在底部摇尾巴 字幕慢慢 zoom + 老鼠尾巴抖动 loop "M-O-U-S-E-C-L-A-W。记住了？"
注意几个病毒性细节：
  • 0-2s 不配音，让画面情绪先到位（"限流烦躁" 是视觉就能传达的）
  • 23s 那个 Spotlight 搜索动画是关键 —— 模拟用户已经在搜了，引导他模仿
  • 结尾"M-O-U-S-E-C-L-A-W 记住了？"是直接对观众发问，强化记忆 + 互动
  • 不用 "下载链接见简介"，反复说 "GitHub 搜" —— 让用户觉得"找到 = 自己的本事"

⑦ 文件输出 + 你怎么剪

  1. 我下次会话写完 demo 1 hyperframes → 跑 npx hyperframes render 出 无声视频 marketing/demo-zh/renders/demo-zh_xxx.mp4（30s · 1920×1080 · 30fps）
