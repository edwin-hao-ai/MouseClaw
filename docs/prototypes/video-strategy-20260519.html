① 病毒化要解决的核心矛盾

MouseClaw 卖点是 "桌面上养一只老鼠 + 语音召唤本地 AI"，但短视频用户看到「桌宠」会想到老款桌面玩具，看到「AI」会想到 ChatGPT。两个标签都太常见 = 滑走。

必须找一个 3 秒内让人停下来的"反差点"。我列了 6 个候选 hook：

Hook反差感3 秒内能 get 吗
「这只老鼠会写代码」玩具 vs 生产力✅ 强 — 立刻好奇
「我开除了 ChatGPT，请了一只老鼠」云 AI vs 桌宠⭐ 最强 — 自带话题
「我电脑里养了 Claude」抽象 vs 具体生物✅ 强 — 但需要懂 Claude
「按住空格 + 说话，AI 帮我打字」键盘 vs 嘴⚠️ 中 — 像 Siri 平淡
「12MB 的桌面 AI 助手」体积 vs 能力⚠️ 弱 — 只有开发者懂
「拖一份文件给老鼠，它就懂了」动作隐喻✅ 强 — 视觉直观
我的判断：主推方向 「我开除了 ChatGPT，请了一只老鼠」（脚本 A）。次推 「拖一份文件给老鼠，它就懂了」（脚本 B，更适合喂桌宠功能展示）。

为什么这个最容易爆

  • 3 秒钩子是公愤 — ChatGPT 用量限制 / 数据隐私 / 国内访问难，三选一就有共鸣

  • 3 个 demo 不重复 — 改文 / 喂文档 / 语音打字，覆盖不同需求场景
  • "100% 本地"是社交货币 — 隐私党会主动转发

③ 配音方案选择

🤖 AI 配音（推荐）

用 ElevenLabs / 火山引擎 TTS / 11labs 中文女声"思琪"或男声"硕"

✅ 零成本反复改

✅ 中英文切换流畅（适合脚本 A 跨语言）

⚠️ 抖音算法识别 AI 配音可能限流（实测 2025-2026 限流减弱了，但仍建议加点真人编辑）

🎙 真人配音

你自己 / 配音平台（喜马拉雅认证主播 ~50-200 元/条）

✅ 不限流，平台权重高

✅ 情绪起伏自然

⚠️ 改脚本要重录

⚠️ 你自己的口音 vs 主播口音差异

🔇 纯字幕 + BGM

不配音，靠剪辑节奏 + 大字幕 + 音效

✅ 最快出片（1 小时能做）

✅ 通用 — 不分语言区

⚠️ 35s 不配音很考验剪辑节奏

⚠️ 信息密度不够，完播差

我推荐的组合：脚本 A + AI 配音中文版（火山引擎"晓萌"女声，活泼）→ 抖音 / 小红书 / 视频号。 脚本 A + 你自己英文真人配音 → TikTok（中文配音 TikTok 算法会限流；英文你本人录更地道）。 脚本 B 做小红书第 2 条增量内容。脚本 C 留给 B 站 / X 时再做。

⑤ 关于"网址" 与 GitHub 引导

用户提到「视频上可能不能有导流的网址」—— 实测 2026 现状：

  • 抖音：视频画面里直接出现 github.com/... 完整 URL 会限流。但 口播 + 字幕「GitHub 搜 MouseClaw」是 OK 的（关键词检索不算导流）。
  • 小红书：URL 一律不行，但能在评论区写。视频内说"GitHub 搜项目名"算正常。
  • 视频号：可以在文末引导关注公众号；视频内说项目名 OK。
  • TikTok：bio link 是合规出口，视频画面里出现 github.com/... 不会被罚但完播率会差。

统一策略：所有平台视频结尾都是「GitHub 搜 MouseClaw」字幕 + 口播，不放完整 URL。
