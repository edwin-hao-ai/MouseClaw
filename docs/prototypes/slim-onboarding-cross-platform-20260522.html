跨平台精简 Onboarding

§4 决策 #3「精简版（跳过权限页）」的落地预览。非 macOS 平台没有 TCC 权限三连， 听写也改用固定全局快捷键（不需要选 mac 修饰键），所以 onboarding 从 7 步缩到 5 步。 每个保留步骤的视觉跟现有 macOS onboarding 完全一致 —— 这里只展示"哪些步骤被跳过"。

🍎 macOS 7 步（不变）

1召唤快捷键
2AI 后端
3挑桌宠皮肤
4语音触发键按住 fn/⌥/⌃…
5桌宠住哪（anchor）
6权限三连辅助功能/录屏/麦克风
7浏览器 + Office 能力

🪟🐧 Windows / Linux 5 步（精简）

1召唤快捷键
2AI 后端
3挑桌宠皮肤
4语音触发键跳过 · 用 Ctrl+Alt+I
5桌宠住哪（anchor）
6权限三连跳过 · 无 TCC
7浏览器 + Office 能力
实现方式：前端用 navigator.userAgent 判平台，非 mac 时 第 3 步「下一步」直接跳到第 5 步、第 5 步「下一步」直接跳到第 7 步；被跳过的第 4/6 步不再渲染。 按钮文案也随之切换（"下一步：选个家" / "下一步：增强能力"）。
Wayland 补充：首次截图时桌面 portal 会弹一次授权框（不在 onboarding 里，属系统级）， 这是 Wayland 的运行时授权，无法前置。
待你拍板：若想在非 mac 也保留一个"提示页"（例如告诉 Linux 用户装 speech-dispatcher 才有 TTS），告诉我，我加一页轻提示而不是直接跳过。
