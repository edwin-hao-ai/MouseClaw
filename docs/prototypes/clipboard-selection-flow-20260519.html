Action items will be tracked in Linear.

⌘⌘ 双击 = 唤老鼠到选区

✅ 工程上的好处

  • 零监听不订阅 Accessibility selection-changed，零隐私焦虑
  • 零权限只需要全局快捷键 + 剪贴板读写（这俩已经有）
  • 已验证PopClip 用同样的模拟 ⌘C 抓选区模式跑了 10 年
  • 主动意图双击是肌肉记忆动作，触发即代表"我要处理"

⚠️ 要小心的地方

  • 恢复剪贴板抓选区前要先存原剪贴板，处理完恢复，否则用户原本想 paste 的东西就丢了
  • 无选区降级用户没选东西就双击 → 老鼠不弹按钮，直接走召唤模式
  • 老鼠位置用 Accessibility 拿到选区屏幕坐标可能慢 100ms，先用"屏幕中央 → 滑入"兜底
  • 手势冲突有些 app 用 ⌘⌘ 做切换，要让用户在 Onboarding 选 ⌘ 或 ⌥

⌃Space 召唤 MouseClaw

✅ 工程上的好处

  • 零监听剪贴板复制本身**不**触发 MouseClaw 任何行为
  • 零打扰用户 200+ 次/天纯搬运复制，老鼠一次都不动
  • 召唤即上下文每次召唤都顺手收集剪贴板 + 选中 + 截图 + 前台 app，一次性
  • 隐私易理解"召唤瞬间读一次"和 Spotlight/Raycast 同性质，用户能接受

⚠️ 要小心的地方

  • 剪贴板过滤密码 / 高熵串 / 银行号要在 prompt 前过滤掉
  • 前台 app 黑名单密码管理器在前台时不读剪贴板
  • 气泡里的提示要"不抢戏"剪贴板那一行只是 hint，不能挤掉用户的主输入意图
  • 忽略也要顺手⌘+2 / 点 X 一键忽略剪贴板，下次召唤不再带
两个流程都在自动循环中（约 12s 一轮）
