③ 实现要点（拍板后给 Rust/TS 用）

敲键即切的判定（前端 listening 视图全局 keydown）

  • 触发切换：e.key.length === 1（单个可打印字符）且 无 metaKey/ctrlKey/altKey → 取消录音、进文字态、把这个字符塞进 input 并 focus
  • 不触发：方向键 / Tab / Shift / Backspace / 功能键（length≠1）—— 留给"未来快捷键"，不误触
  • Esc：listening 态 = 取消召唤；typing 态 = 退回 listening（不是直接消失，给反悔空间）
  • 中文：拼音首字母就是单字符，敲下即切；切后 input 拿到 IME composition，正常拼。无需特判
  • 录音处理：切走时 stop & discard 这一小段音频（别偷偷转写混进文字）—— 干净切换
  • 桌宠状态：listening（耳立+弹跳）→ 一敲键切 type 态（黄铅笔+前倾，盯输入），提交后 think
  • 提交路径：文字 = 语音转写出来的同一条 transcript，走同一个主 pipeline + ai_queue 串行，下游无差别
  • 窗口尺寸：input 气泡比 listening 气泡高 → 走 useAdaptiveOverlay 自适应，别拍 EXPANDED_SIZE
