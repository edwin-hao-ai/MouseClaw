更多候选场景（V1.1 / V2）

🎯 App Pomodoro · 打开 IDE 自动启动 25min 番茄钟
👀 20-20-20 护眼 · 每 20min 老鼠望向远方提醒你也望望
🍕 午餐提醒 · 12-13:30 久坐 → 举叉子问"午饭啦？"
🎵 音乐律动 · 检测 Music/Spotify 播放 → 老鼠跟着晃尾巴
🎂 纪念日 · 装机满 30/100/365 天 → 特殊动画 + 解锁限定皮肤
☔ 天气彩蛋 · 下雨天撑伞，太热擦汗（每天联网 1 次）
🔄 切换疲劳 · 10min 切 app ≥15 次 → "你在找什么呀？" + 一键召唤
🏆 徽章成就 · 早起 5 天 / 召唤 50 次等 → 塞到 🎁 项里，不打扰但可炫耀
🔒 隐私红线（这点必须在 Onboarding 和 README 显著位置说明）
全部信号在本地采集、不联网、不录内容。
• 只数键盘"打了多少下"，不读"打了什么"
• 只看前台 app 名字 + 窗口标题，不抓窗口内容
• 30 分钟环形 buffer，过期自动覆盖，不落盘
• 日历 / 麦克风占用是可选授权，默认关

提醒的"教养"三铁律

  1. 永不打断深度工作 — IDE 高强度敲键时提醒全部排队，等用户停下 ≥2min 才插
  2. 永不重叠 / 永不堆积 — 多个到期 → 只演一个（健康 > 工作 > 彩蛋）
  3. 永远可以"今天闭嘴" — 每个气泡右下角都有 mute 入口，连续 3 天关同一类 → 默认关掉

④ 建议 MVP 切片
