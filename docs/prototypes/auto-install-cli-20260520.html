每条卡都是真跑一次 pipeline（不是录像），第一次成功 = 用户留下来。 失败也别藏，老鼠头顶气泡告诉为啥失败 + 下一步建议。
设计约束 reminder
• 所有 curl|bash / npm i -g 命令必须在「显示完整命令」里全文可见，不藏。
• 没 npm 就不假装能一键装 Node，引导到 nodejs.org 比静默失败强。
• 安装失败的每条路径都给"下一步具体动作"，不甩 stack trace。
• 状态页轮询 1.5s，装完不需要重启 app。
• 跳过永远存在 —— 不强制，但默认勾上。
• 装完主动告诉用户老鼠学会了新技能（State 7），不让用户自己摸索。
• 教程 = learn-by-doing（State 8），真跑一次 pipeline，不是录像 / 文字说明。
• 主动调用 = 启动时探测 CLI · 拼进 system prompt · 让 Claude 知道老鼠真有这两只手。
