Reactive 老鼠 · 三层反应模型 prototype

老鼠永远在桌面角落。复制 / 选词 → 它立刻有反应 —— 但 99% 情况只是像素动画（耳朵抖一下、眼睛瞟一下）， 不弹按钮、不出 UI。"看着值得"时才升到 tier 2（头顶飘小图标），用户主动 hover 老鼠才到 tier 3（动作面板）。 下面同屏展示三层、suppression 规则、强度档位、和完整剧本动画。

1 · 三层反应总览

Tier 1 · 察觉

~200 次/天 · 持续 ~400ms · 零 UI

每次复制 / 选词都触发。表现：耳朵抖 / 眼睛瞟向光标方向。不弹任何东西 —— 它只是让你"知道老鼠看见了"，像家里的猫。

Tier 2 · 提示

~30 次/天 · 持续 2-3s · 头顶小气泡

内容判断为"值得处理"（长 / 跨语言 / 像代码 / 像 URL）时升级。头顶飘一个小图标，2-3s 自动消失。不打断当前操作。

Tier 3 · 展开

~5 次/天 · 用户主动 hover/点 老鼠

用户走过去碰一下老鼠 → 弹出动作面板（翻译 / 解释 / 润色 / 总结 / 自定义）。点完结果回写剪贴板 + 气泡确认。

2 · 完整剧本动画 复制乱码 → 老鼠抖耳 → 飘图标 → hover 展开 → 选清理 → 写回剪贴板

3 · 静音规则（老鼠完全不动的 4 种情况）

🔇 短复制

复制了 "OK" / "Yes" / 短 URL

长度 < 20 字符 → 老鼠睡着，连耳朵都不抖。99% 是搬运操作。

🔇 2s 内 paste

复制后立刻 ⌘V

纯搬运闭环 → 老鼠刚抖的耳朵立刻收回，不进 tier 2。

🔇 高熵串

复制看着像密码 / token / API key

shannon entropy > 4.5 或长度 16-64 的 base64 风格 → 不读内容、不进 prompt。

🔇 敏感前台

1Password / Bitwarden / 银行网页在前台

整个 ambient 通道直接关掉，老鼠睡觉直到切走。

4 · 用户可调"反应强度"

老鼠反应强度
🌙 安静
只 T1（抖耳） · 任何复制 / 选词都不弹小图标
⚖️ 标准（默认）
T1 + T2 · "值得处理"才飘图标
🔔 主动
T1 + T2 + 文字判断为另一种语言时自动翻译写回

💡 这一层 = 老鼠的"性格"在产品里真正的体现：学者鼠默认"安静"，段子鼠默认"主动"， 打工鼠默认"标准"。Persona 不是 framework，就是一个 string + 一组默认值。
