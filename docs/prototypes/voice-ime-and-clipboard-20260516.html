🦞 MouseClaw v0.2 · 桌宠变 daily-use 工具

语音输入法 + 剪贴板历史 + 点击桌宠唤出 Hub · prototype 2026-05-16

从 "AI 助手" → "随手就在那儿的桌面伴侣"

v0.1 的桌宠只在按 ⌘⇧Space 想问 AI 时才出现。v0.2 把它变成你**日常每分钟都会用**的东西 —— 按住 fn 说话就直接打字（语音输入法）/ 每次复制都被记下来（剪贴板历史）/ 点桌宠就能选东西粘贴（不用切第三方 app）。AI 召唤仍在但变成「特殊场景」按钮。

① 三套快捷键的分工

三种触发方式，三种心智模型，绝不重叠。

快捷键意图桌宠去哪结果
fn 长按 默认 "帮我打字" — 语音输入法 跑到光标位置 松开 → 转写文字直接写到光标，**不调 AI**
⌘⇧Space 按住 "帮我想想" — AI 召唤 截屏 + 录音 → AI 处理 气泡里出回答（Mode A）或写到光标（Mode B）
⌘⇧V 新 "翻一下我刚复制过什么" 就地展开 Hub（剪贴板 tab） 选一条 → 粘到光标
左键点桌宠 新 "看看我的东西" 坐下，旁边展开 Hub 剪贴板 / AI 历史 / 设置 三个 tab
为什么选 fn？ macOS 上 fn 单独按时几乎没有原生用途（仅在某些 MBP 上是 "showing emoji"），且 Apple 自己的 Dictation 也用 fn——用户已经被训练好「fn = 语音」。⌥ 单独 hold 会跟 ⌥+click/drag 冲突； ⌃ 也是大量 app 内 shortcut 的 modifier。fn 是唯一"安全的孤立键"。

② 长按 fn → 语音输入法（最高频功能）

桌宠跑到光标边，说话即打字。不调 AI，纯转写。这是 daily-use 的核心场景。

交互流程

按下 fn (>250ms) 桌宠瞬移到光标右下角，pet 进入「type」态：盯着光标，前爪上举做笔状
开始说话 "voice bars" 跟着音量跳。Whisper 持续 streaming（v1：松开后一次性转）
松开 fn 转写文本通过剪贴板 fallback / CGEvent 直接写到光标，桌宠原地跳一下 → 消失

边界情况

  • 终端前台 → 仍 suppress（防止意外回车执行命令）
  • 密码字段 → 检测 secure text input → 直接放弃，弹气泡提示
  • 按下不到 250ms → 视为误触，桌宠不出现
  • 录音中切走前台 → 取消，丢弃录音
  • 录音 > 60s → 强制截止 + 提示 ("一次最多 60s")

③ ⌘⇧Space → AI 召唤（不变）

原 v0.1 的核心功能 —— 截屏 + 录音 + AI 处理 + Mode A / Mode B 输出。这里保留不变。

④ 点击桌宠 → Hub（新交互骨架）

桌宠是"常驻你屏幕角落的小宠物"，点它 = 调出最常用的两个东西：剪贴板 + AI 历史。

触发方式

  • 左键点桌宠 → 旁边展开 Hub 面板（同窗口内，玻璃质感）
  • 双击托盘图标 → 也打开 Hub（无桌宠状态下的入口）
  • ⌘⇧V → 直接跳到剪贴板 tab + 自动聚焦搜索框
  • Esc / 点 Hub 外 → 关闭，桌宠归位

Hub 结构

  • 顶部 tabs: 📋 剪贴板 / 💬 AI 历史 / ⚙️ 设置
  • 搜索框: 实时模糊匹配，跨 tabs 全局
  • 列表: 可选项, ↑↓ 高亮, ↵ 选中
  • 1-9 快选: ⌘1..⌘9 直接选第 N 条
  • 底部: 当前 tab 数量 + 「清空」按钮

⑤ 剪贴板历史的详细设计

这是 v0.2 真正能让用户每天 "离不开" 的功能。借鉴 Raycast / Paste 的最佳实践。

数据模型

{
  "id": "0a3f...",
  "kind": "text" | "image" | "file" | "url",
  "preview": "前 200 字符",       // 列表显示用
  "full": "原文..." | path,       // 粘贴时用
  "app_bundle": "com.microsoft.VSCode",
  "app_name": "VS Code",
  "ts": 1715890234,
  "pinned": false                 // ⭐ 用户标星不删
}

存：~/.mouseclaw/clipboard/YYYY-MM-DD.jsonl · 图片存 clipboard/img/id.png

捕获策略

  • 轮询 NSPasteboard changeCount 每 500ms（vs 注册 NSPasteboardObserver — 不存在；轮询是 macOS 标准做法）
  • 排除应用：1Password / Bitwarden / Keychain / Terminal / 用户自定义列表
  • 排除 "transient" ：NSPasteboardItem 标记 org.nspasteboard.TransientType 的不存（密码管理器约定）
  • 体积上限：单条文本 1 MB / 图片 5 MB / 文件只存路径
  • 保留时间：默认 7 天，⭐ 标星的永久
  • 去重：同内容连续复制 → 只保留最新一条 timestamp

⑧ 隐私 / 安全考虑（剪贴板的硬约束）

剪贴板历史是最敏感的本地数据。任何 daily-use 剪贴板工具的成败关键在这里。

✅ 必做

  • 遵守 transient 类型：检测 org.nspasteboard.TransientType / org.nspasteboard.ConcealedType → 完全不存（1Password/Bitwarden 等都打这个标）
  • 默认排除应用：1Password, Bitwarden, Dashlane, KeePass, Keychain Access, Terminal/iTerm/Warp
  • 纯本地存储：永远不上传，永远不进 telemetry。clipboard.jsonl 在 ~/.mouseclaw/，权限 0600
  • 磁盘加密：v0.2 用 macOS Keychain 存对称密钥 → 文件 AES-256 加密（仅当前用户能读）
  • 用户可清空 / 暂停：Hub 底部「暂停记录」开关 + 「清空全部」按钮（带确认）
  • 密码/secure 字段提示：粘贴前检测前台是否 secure-text-input → 拒绝并提示

⚠️ 不做

  • 不做云同步（哪怕用户要求 — 这是 daily-use 工具，多设备同步是另一个完全不同的安全模型）
  • 不上传任何剪贴板内容到 AI 后端（AI 召唤是单独的流程，不复用剪贴板数据）
  • 不做"基于剪贴板内容的智能推荐"（会激励我们偷看用户内容）
  • 不记录密码管理器粘贴出来的内容（即使用户没把它加排除名单）
第一次启动剪贴板功能要弹的 onboarding： "我会在本地记录你的复制历史，永远不联网。 默认会跳过密码管理器和终端。可以随时关掉。" + 一个清晰的 ✅ / ❌ 选择。

⑨ 实现路线图（建议）

阶段范围预估难点
P0 必做 剪贴板历史捕获 + 持久化 + Hub 列表 UI 1 天 NSPasteboard 轮询的省电策略；transient 标志识别
P0 必做 点击桌宠 → Hub 展开 + Tabs 框架 0.5 天 Tauri 窗口尺寸动态调整（pet-only → pet+hub）
P1 高优 长按 fn → 语音输入法（写到光标） 1 天 fn 单键长按检测；与系统 Dictation 抢占；< 250ms 误触保护
P1 高优 ⌘⇧V 直接打开 Hub + 自动聚焦剪贴板搜索 0.5 天 全局快捷键注册（已有基础设施）
P2 AI 历史 tab 合并进 Hub（替代独立 history 窗口） 0.5 天 复用 read_history 命令；session 视图重排
P2 kind 自动识别（URL / 颜色 / 文件路径）+ 图片预览 0.5 天 NSPasteboard image type 读取；缩略图缓存
P3 磁盘 AES 加密 + Keychain 密钥管理 0.5 天 macOS Security framework 集成
P3 ⌘1..9 快选 / 拖出 Hub 到 app / 桌宠 3 个新状态 1 天 NSDragging 协议；新 sprite 设计（6 款皮肤 × 3 新状态 = 18 个新像素图）
