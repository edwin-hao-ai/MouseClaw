用哪个 AI 后端？

这个 prototype 在验证什么

  • 只列已安装的（用户决策 2026-05-22）：选项只放机器上真有的 CLI，没装的不当主选项 —— 不再让人"选了它却不工作"。
  • 默认就帮你选好：装了多个时，按优先级(Claude→Codex→Gemini…)自动选第一个能用的，用户直接点"下一步"即可。
  • 发现性兜底：未装的收进「▾ 查看全部 13 个后端」，给一键复制的安装命令 —— 想用别的也找得到，但不挡路。
  • 一个都没装 → 推荐：不给空列表，直接推荐 Claude + 可复制命令 + 「重新检测」。装完点一下就进来了。
  • 登录类后端(Copilot/Antigravity)标 黄 pill：提示去终端登录，而不是让你填 key。
  • 复用现有 check_backend_installed（只查二进制在不在 PATH，零 API 开销）。"真能跑"的探针(ping)是另一条更重的线，可后加。
