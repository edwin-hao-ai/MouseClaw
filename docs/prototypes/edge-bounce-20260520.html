这个 prototype 想让你拍板的几点：
1. 软 vs 硬：默认全员用「软果冻」。机器鼠 / 忍者这种"硬"角色要不要单独走「硬·脆点」？（顶部切换看对比）
2. 回弹幅度：现在挤压到 ~0.78、回弹 ~8px。太夸张？太含蓄？
3. 撞击星星 ✦：要不要这个小反馈？还是太花、跑 50 次会烦？
4. 触发频率：只在"首次贴到墙"弹一次，贴着墙拖不会连发（已实现，可贴着边来回拖验证）。
实现路线（拍板后）：Rust 端 clamp 时若发生位置修正 → emit 一个带方向的 edge-bonk 事件 + 把"权威锚点"保持为未 clamp 的真值（治漂移）；React 桌宠收到事件给 .pet-svg 加对应 bonk-{dir} class 播一次动画。纯 transform，对 9 款骨架一视同仁。
