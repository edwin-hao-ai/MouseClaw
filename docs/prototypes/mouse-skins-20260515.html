4. 设计决策

  • Anatomy 仍锁定：每款都在同一 16×16 网格上画 —— 不破坏 DESIGN.md §3.1 的 anatomy 约束。差异 = (a) 每款独立的 8 色调色板 + (b) 极小的体型/配件微调 （耳朵大小、尾巴长短、头饰一两个像素），不会出现完全不同的造型。
  • 每款 ≤8 色：仍尊重 NES-style 限色，只是不同皮肤用不同的 8 色组合。 需在 DESIGN.md §2.1 新增「Skin Palettes」表，列出每款的 token map。
  • 所有状态 (sleep/listen/think/write/jump/block) 都得各自渲染一遍 —— 但因为眼睛 / 嘴 / 道具是按 state 决定的，每款只需复用 PixelMouse.tsx 的 Eyes/Extras 组件 + 自己的 palette CSS variable。代码改动小。
  • 切换入口：Onboarding 加第 4 步「挑你的桌宠」（默认经典灰）+ 托盘菜单加「🎨 换个桌宠 ▸」子菜单（实时切换、立即生效）。 config.json 加 skin: SkinId 字段，schema v6→v7。
  • 未来扩展：拿到这套 token 化框架后，加新皮肤 = 加一组 CSS 变量 + 一行 SkinId 枚举。不需要改任何渲染逻辑。
