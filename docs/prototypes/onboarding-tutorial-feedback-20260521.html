这个 prototype 演示什么

  • ① 真实忙碌反馈：点「试这条」→ 该卡变「⏳ 演示中」+ 顶部出现 老鼠演示中 横幅。绑定真实 bg-task-changed 事件，不是瞬闪。
  • ② 防连点 / 串行：演示中其余两张卡变灰不可点（AI 任务串行）。演完该卡变 ✓ 演过了（可 ↻ 重跑），全部恢复。
  • ③ 完成中断保护：演示中点「完成 / 跳过」→ 弹确认 [等演完] / [直接完成]。任务卡住也能强制完成，不困住用户。

试试：点任一「试这条」（模拟 4s 演示），演示中再点别的卡 / 点「完成」看效果。
