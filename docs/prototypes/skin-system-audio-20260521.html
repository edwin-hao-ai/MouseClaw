🔊 皮肤音效系统

给桌宠的动画 / 状态加音效：睡觉有轻微鼾声、完成任务有提示音、点一下有吱声…… 所有声音用振荡器**实时合成**（chiptune 8-bit 风），不打包任何音频文件。 4 个物种各有自己的"嗓音"——同一个事件在老鼠 / 猫 / 狐 / 蛙 身上音色不同。 先点下面试听、调音量、感受会不会吵，确认方案后我再写 Rust/TS（见底部）。

这个 prototype 在演示什么 / 接下来怎么落地

声音全部由 AudioContext 振荡器实时合成 —— DMG 体积不增加，可任意调参，天然贴合像素美术。 事件→状态映射直接对应现有的 MouseState 与 CompanionState。

事件 ↔ 状态映射（已对照源码）

  • 任务提示：task-done=jump(A 模式回复完成) · error=block · feed=feed-digest · insert=paste(B 模式写入) · link=续 session · levelup=亲密度升级 · nudge=主动提醒
  • 环境：snore=sleep / companion sleep（循环，最易吵，单独可关）
  • 微反应：squeak=clicked · hop=hop(打字结束蹦) · excited=cursor 贴近 · dizzy=甩鼠标 · bonk=撞墙 · wake=waking

"会不会吵"的设计取舍（请重点感受）

  • 三类独立开关 + 总音量；微反应(点击吱声)触发最频繁，建议默认关，你听完拍板。
  • 鼾声循环最易腻：默认很轻、每 ~3.5s 一次（非持续嗡嗡），可单独静音。
  • 同一音 400ms 内不重复触发（节流，已内置）。
  • 正在 TTS 朗读时应自动让位（app 端会接 tts 状态，prototype 未模拟）。
