③ PRD 补齐 — 多后端 + Compute Use

新功能

多 AI 后端（Claude / Codex / OpenClaw CLI）

  • config.json 加 backend 字段，schema 版本 v5→v6（旧 config 自动重走 Onboarding）。
  • Onboarding 从 2 步改 3 步：选快捷键 → 选 AI 后端 → 开权限。 save_shortcut(choice, backend) 前后端接线完成。
  • 没装/没配的后端在调用时报清晰的安装指引错误（如 npm i -g @openai/codex）。
新功能

Compute Use — 浏览器自动化 / 自动填表

  • 调研结论：选 Vercel Labs 的 agent-browser —— Rust 原生、headless、 CLI-first、macOS 原生二进制、紧凑文本输出（省 context），14k+ stars。最贴合 MouseClaw 「shell out 到 CLI」的既有架构。
  • 实现方式（关键决策见下）：不自己造 Mode C 引擎，而是 system_prompt() 检测到本机装了 agent-browser 时， 往 system prompt 追加 BROWSER_CAPABILITY_PROMPT —— 告诉后端「你的 Bash 工具里有这个 CLI，需要操作浏览器/填表时调它」。
  • compute use 能力随后端 agentic 能力自然获得，零新增安全面； prompt 里明确要求「提交订单/付款/发消息等不可逆动作先停下来让用户确认」。
